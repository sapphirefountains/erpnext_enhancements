{# Time Kiosk PWA app shell (served at /kiosk; controller: kiosk.py). This is the installable Progressive Web App's HTML shell, not the app itself. It is a thin chrome-free page whose only jobs are to: * apply the stored theme BEFORE the stylesheet is parsed (the inline script at the top of head_include — see "Theme" below); * declare the PWA (web manifest, theme-color, Apple/standalone meta tags, touch icon) so the browser offers "Install app"; * load the kiosk styles (css/kiosk/kiosk.css) and front-end scripts (js/kiosk/ui.js, geo.js, myday.js, map.js, settings.js, app.js — in that order; app.js mounts the others); * hand the server-computed boot payload to the front-end as window.KIOSK_BOOT / window.KIOSK_CSRF / window.KIOSK_BUILD (see kiosk.py::get_context). The actual UI is rendered client-side by app.js into #kiosk-root. Theme: three-way — light / dark / system, system the default. The user's choice lives in localStorage.tk_theme and is expressed as ; the attribute is ABSENT for system, and kiosk.css's dark palette then follows prefers-color-scheme. The inline script below runs before the stylesheet so the first paint is already the right colour (no flash). It is wrapped in try/catch because localStorage throws in some private / embedded contexts. KioskUI.theme (ui.js) owns every later change and keeps the theme-color meta equal to the resolved --tk-bg. tests/test_kiosk_theme.py pins the ordering. Offline strategy: the root-scope service worker (kiosk-sw.js, registered by app.js) precaches this shell and these assets, so the app launches and runs without a network. Geolocation points are queued in IndexedDB and uploaded in batches with Background Sync retry. See kiosk-sw.js for the full lifecycle. Leaflet (Map tab) is NOT precached — it is loaded lazily from frappe's vendored copy and the tab says so when offline. Cache busting: raw /assets are served with a 1-year immutable Cache-Control, so every mutable asset URL below carries ?v={{ deploy_version }} (a token that changes on each bench build — kiosk.py::get_deploy_version). A deploy therefore gives the browser brand-new URLs, and window.KIOSK_BUILD versions the service-worker registration so its cache rotates too. The icons stay unversioned on purpose: their content never changes (same rationale as the vendored libraries in hooks.py). Every raw `?v=` js/css URL here must also be in the worker's PRECACHE (tests/test_kiosk_frontend.py checks both directions).
