# chat Phase 5 (v1.272.0). The retrieval composites, and one raw-DDL FULLTEXT index that has

# column is a prefix index or an error, never a FULLTEXT index.
#
# A third file rather than rows appended to add_chat_phase2_indexes, for the reason that file
